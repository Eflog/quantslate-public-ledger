How this works

  • The model is a calibrated gradient-boosted classifier of home-team win probability, trained on NFL history. Picks are the side whose model probability is higher than the market's after converting the point spread to a probability.
  • The ledger is append-only. For each game, the last snapshot taken before kickoff is the one that counts; later snapshots are ignored.
  • Grading: flat 1 unit per pick at an assumed -110 price (win +0.91u, loss -1u, push 0). Real prices vary by sportsbook and by day.
  • Lines come from the market data listed in each row's source (live book consensus or the nflverse schedule line). The line at the time of the pick is the line used for grading.
  • Games with no posted line are not recorded.

0 of 0 graded picks were timestamp-anchored: their hash was posted to a public Discord channel, which stamps each message with its own time. Hash records (CSV). To check the ledger yourself, clone the repository and run python verify_ledger.py.

Every snapshot is committed to the public repository (https://github.com/Eflog/quantslate-public-ledger) at the time it is generated. Compare the 'Locked' time on any row with the commit history of ledger/picks.csv and with the game's kickoff time. Git commit dates can be set by whoever makes the commit, so the push times shown in the repository's activity feed are the stronger evidence.
